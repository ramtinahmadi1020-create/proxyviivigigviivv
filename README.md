# Cloudflare Proxy Worker

با کلیک روی دکمه زیر، این پروژه به صورت خودکار روی کلودفلر دیپلوی میشه:

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/ramtinahmadi1020-create/proxy)

> **نکته:** بعد از دیپلوی، اگر نیاز به تغییر رمز `ADMIN` یا `UUID` داشتی، از داخل داشبورد کلودفلر بخش Settings > Variables این کار رو انجام بده.
